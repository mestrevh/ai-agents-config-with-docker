# Arquitetura

<arquitetura>
As soluções desenvolvidas devem seguir princípios de alta coesão, baixo acoplamento, SOLID e separação de responsabilidades. O código deve ser legível, modular e auto-documentado, priorizando testes automatizados e segurança no gerenciamento de dados.
</arquitetura>

---

# Transformar

<transformar>
- Evite funções longas ou classes com múltiplas responsabilidades.
- Não inclua dependências desnecessárias ou código morto.
- Mantenha tratamentos de exceção explícitos sem ignorar erros silenciosamente.
</transformar>
